# The Poem 品牌搜集 · 试用下载

按每个项目的需求，发现国内外合作品牌，核实来源与业务联系方式，并生成招商 Excel。

## 下载

前往 [试用版 Release](https://github.com/gabrielle-xue/poem-brand-discovery-downloads/releases/tag/v0.1.0-beta.1)，在 **Assets** 下载对应 ZIP：

| 使用方式 | 下载文件 |
| --- | --- |
| Codex，或 ChatGPT Work 的单技能上传入口 | `poem-brand-discovery.zip` |
| ChatGPT Work 管理员的插件上传入口 | `poem-brand-discovery-plugin.zip` |

**两个 ZIP 不需要同时安装。** 不要下载 GitHub 自动生成的 Source code ZIP，它不是安装包。若 Release 尚未发布，请稍后再试。

详细步骤见 [安装与试用说明](INSTALL.zh-CN.md)。首次建议先做离线安装验收，再使用自己的项目 brief 开始研究。

请在受团队认可的私密会话或工作环境中提交项目资料；**不要把内部 brief、合作资源、联系人或研究结果上传到本公开仓库和 Issues。**

- GPT Work 已完成一次粤海天地新店 10 品牌实际测试。
- 已验证本地 Linux Python 3.12 下的安装与 Excel 导出；公开下载包重新检查 ZIP 完整性、文件清单和逐文件校验。
